# v1.2 Design — Portrait Layout + Natural-Persian Polish

**Date:** 2026-10-12 · **Status:** approved in chat · **Target output:** `SUT_Physics_Career_Guide_v1.2.pdf`

## Context

v1.1 (52 pages, 1.04 MB) ships with 11 landscape pages in 4 runs (pp. 15–17 جدول ۵.۱ · 28–30 جدول ۹.۱ · 33–35 جدول ۱۰.۱ · 37–38 جدول ۱۱.۱). Channel feedback:

- **امین عزیزی:** mid-document landscape flips break reading flow → all pages must be portrait.
- **ENZO:** unnatural wording — quoted the ch1 opening word by word: «درباره»، «فرایند اپلای»، «ضرب‌الاجل»، «لایهٔ تحریم» (mocked as «ابریشم تحریم؟ پارچهٔ تحریم؟»), stray tanvin in «عمداً شواهدمحور», «کلی چیز نامونس دیگه از نظر جمله‌بندی و نگارشی». Also «متن کپشن خوانا نیست» — written *before* he opened the PDF, so it refers to the channel-post text / cover preview, not interior captions.

## Goals

1. Zero landscape pages; four wide tables re-fit into portrait A4 (~16.6 cm text width) without content loss.
2. Full line-edit of the Persian prose for natural, contemporary register — sentence rewrites authorized; **every number, fact, source, link, and table cell content preserved verbatim in meaning**.
3. Cover audit + version bump to «نسخهٔ ۱٫۲»; remove leftover internal-report references.
4. Deliver a channel-post blurb (text file) alongside the PDF.

## Non-goals

No new content or data changes · no changes to portrait-native tables (۳.۱، ۴.۱) · no font family changes · no folio scheme changes (الف/ب/پ front matter, ۱/۲/۳ from ch1) · v1 and v1.1 PDFs stay byte-untouched.

## Design

### 1. Workflow

- All content edits live in `source/refine.py` as new v1.2 sections appended after the existing v1.1 pass (single deterministic chain `guide_v1_original.html → guide.html`). v1.1's section 10 (landscape wrapper injection) is **replaced** by the v1.2 portrait/unwrapper transform.
- `source/style.css`: delete `@page land` master + all `.land*` rules; add compact-table rules.
- `source/build.py`: change `OUT` to `../SUT_Physics_Career_Guide_v1.2.pdf`. The landscape branch in `overlay()` is harmless generic code — leave it.
- Rebuild: `python refine.py && python build.py` (Python 3.11.4 at `/c/Program Files/Python311/python`; weasyprint 68.1 + fitz installed; pikepdf NOT installed; GLib UWP warnings are noise).

### 2. Landscape → portrait

- **Unwrap:** remove the v1.0-inherent `<div class="land">…</div>` wrappers around the four tables (caption + table stay in normal flow); do not inject any v1.1 wrappers.
- **Compact class** `tbl-c` applied to tables `tab-5-1`, `tab-9-1`, `tab-10-1`, `tab-11-1`:
  ```css
  table.tbl-c { font-size: 9pt; }
  table.tbl-c th, table.tbl-c td { padding: 3pt 5pt; line-height: 1.45; }
  ```
  Optional per-table `<colgroup>` width hints if the visual pass shows squeezed columns.
- **جدول ۵.۱** (4 cols × 16 rows) and **جدول ۱۱.۱** (5 cols × 6 rows): compact only; narrow key column («خانوادهٔ شغلی» / «سال»). Expected ≈2 and ≈1.5 pages.
- **جدول ۹.۱** (4 cols × 15 rows): compact; `thead { display: table-header-group }` already repeats headers on breaks. Expected ≈3 pages.
- **جدول ۱۰.۱** (6 cols × 15 rows → **4 cols**), via a deterministic row-merge transform in refine.py:
  - New header: `شغل | چرا فیزیک‌دان می‌خواهد | ایران / خارج | ورود و اطمینان`
  - «ایران / خارج» cell = `<strong>ایران:</strong> {old داخل-ایران cell}<br><strong>خارج:</strong> {old خارج cell}` — cell text verbatim, labels added.
  - «ورود و اطمینان» cell = `{مقطع ورود} · {اطمینان}` (e.g. «BSc/MSc · بالا»).
  - The transform must assert exactly 15 body rows merged and balanced `<strong>` tags.
- Chapter openers return to standard `.chap-open` portrait margins (automatic once `.land*` rules are gone). Expected total ≈55 pages.

### 3. Prose line-edit (full read-through)

- **Ch1 opening rewrite (approved sample):**
  - «اضطرابی که دانشجویان ما دربارهٔ آینده و فرایند اپلای گزارش می‌کنند واقعی است و ساختارش هم واقعی است: چند ضرب‌الاجل هم‌زمان، یک لایهٔ تحریم که می‌تواند شبی یک برنامه را به‌هم بریزد، سربازی برای برادران، و محیطی پر از شایعه.»
    → «اضطرابی که دانشجویان ما دربارهٔ آینده و اپلای دارند واقعی است، و دلایلش هم واقعی‌اند: چند ددلاین هم‌زمان، تحریم‌هایی که ممکن است شبی همه‌چیز را به‌هم بریزند، سربازی برای برادران، و محیطی پر از شایعه.»
  - «این راهنما عمداً شواهدمحور نوشته شده نه انگیزشی» → «این راهنما آگاهانه شواهدمحور نوشته شده، نه انگیزشی»
- **Mechanical sweeps (word-level, counted `rep`s):**
  - «ضرب‌الاجل» → «ددلاین» (×1)
  - unify «فیزیکدان» → «فیزیک‌دان» (ZWNJ)
  - unify «مهارتمحور» → «مهارت‌محور»؛ «دانش‌گاه‌های» → «دانشگاه‌های»؛ «ریز‌عدسی» → «ریزعدسی»
  - «بدتر‌شدن» → «بدتر شدن»؛ «سافتهای» → «سافت‌های»؛ «فکرتانک‌ها» → «اندیشکده‌ها»
  - «اپلیکیشنفی» → «هزینهٔ درخواست (اپلیکیشن فی)»؛ «هم‌دوره تحریم شده» → «هم‌زمان با دورهٔ تحریم» (rephrase in place)
- **Judgment-call items** (decide at execution, record in the edit list): «رونویسی» where it means transcript (→ «کارنامه»)، «فرایند پواسون مزدوج» (→ «مرکب» — compound Poisson), «گازهای یونیده» (likely keep), any «فرآیند» with hamza (0 found today).
- **Process:** read guide.html chapter by chapter; every clunker becomes an explicit `rep(old, new, count)`; sentence rewrites never via blind regex — literal strings only. Meaning/facts/numbers immutable.
- **New end-of-refine checks:** banned list must return zero hits in body: «ضرب‌الاجل», «لایهٔ تحریم», «فرآیند», «مهارتمحور» (without ZWNJ), «سافتهای» — plus all existing v1.1 checks (no Gregorian months/years, no currency signs, no R-labels, no «جدول X-Y»).

## Risks & mitigations

| Risk | Mitigation |
|---|---|
| Portrait squeeze makes cells unreadable (ENZO's core complaint) | 9pt floor, colgroup width hints, visual pass on every table page; escalate to user if any table still looks bad |
| `rep` count mismatches during sweeps | fail-loud counts as in v1.1; anchor longer context strings |
| Rewrite drifts from meaning | literal-string rewrites only; no regex prose edits; spot-check against v1.1 text |
| Page reflow breaks TOC | two-pass TOC numbering already converges automatically |
